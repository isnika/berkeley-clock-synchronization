# Mac development discontinued — 21/11/2026

The team now develops, packages and accepts Windows only. The Avalonia interface
is the primary Windows application at `src/Berkeley.Windows`.

These files preserve the previous macOS work for reference. They are outside the
active projects and CI. The archived solution, scripts and workflow contain old
paths and must not be used as current build/run instructions.

See [the current Windows guide](../../docs/huong-dan-windows.md).
